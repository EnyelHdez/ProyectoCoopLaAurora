
# ProyectoCoopLaAurora
Desarrollar una página web para Cooperativa La Aurora orientada a la publicación de oportunidades de empleo y recepción de currículums de personas interesadas en formar parte de la institución.  La plataforma servirá como una herramienta de apoyo para el área de Recursos Humanos, permitiendo centralizar las informaciones de los candidatos.
